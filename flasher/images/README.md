# Copy release binaries here for a standalone Setup folder

Needed files:

- `bootloader.bin`
- `partition-table.bin`
- `alpha_smart_neo2_buddy.bin`
- `littlefs.bin`

Or leave empty — Setup defaults to `../../releases/1.0.0` (Full) when run from the repo, and also lists `releases/1.0.0-headless`, `releases/1.0.0-uart-slim`, and `releases/custom/*` when those packs exist.
