# Credits and disclaimer

## Thanks

The USB “manager” language the Buddy speaks was figured out largely by studying **[NeoTools](https://github.com/lykahb/neotools)** by [Borys Lykah](https://github.com/lykahb), itself built on earlier work in [AlphaSync](https://github.com/tSoniq/alphasync/). That research is why this project can back up a Neo without turning the writing day into IT support.

[Danny Salzman’s Neo BLE write-up](https://www.dannysalzman.com/2024/06/20/modding-alphasmart-neo-for-wireless-ble-transfer) is useful reading on USB power and ESP32 companions.
