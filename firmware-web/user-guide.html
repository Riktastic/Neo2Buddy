Neo2 Buddy

User guide

Back to portal Live demo

Version 1.0. Primary testing so far is with a Dutch Neo2. UK, US, and other regional keyboard layouts may differ slightly for live typing, Bluetooth passthrough, and file import/export — layout feedback is welcome.

Try the portal first: Documents showcase · Typing & Bluetooth showcase (sample data on GitHub Pages — no hardware required).

1. First connection

  1. Flash with Setup from the GitHub release (Setup-windows, Setup-macos, or Setup-linux) — unzip and run; no extra software. Use a Full (Wi‑Fi) profile, then power the buddy and join its Wi‑Fi hotspot (name starts with Neo2).
  2. Open http://192.168.4.1 (or the address shown on the OLED).
  3. Complete first-time setup: choose Direct access or Home network, set a portal password (8+ characters).
  4. After reboot, sign in with that password. Portal sign-in is required by default.

2. Daily backups

  • Connect the AlphaSmart Neo by USB to the buddy.
  • Turn on Auto on connect on the Documents or Backups panel (or in Settings) to save changed files automatically when you plug in.
  • Use Backup now for changed files only (same idea as Auto on connect), or Backup all to force-save every non-empty AlphaWord slot even if unchanged.
  • Keyboard mode note: scanning, reading, writing, or backing up files switches Neo to manager mode. Live typing / keyboard emulation pauses until backup finishes (or until you tap Keyboard mode after a single file read).
  • Empty or whitespace-only documents are skipped.
  • Backup now / Auto on connect skip today’s file when the bytes match; Backup all rewrites today’s file anyway.
  • On internal flash, oldest backups are removed automatically when space runs low.
  • SD card files are never deleted by factory reset or flash pruning.

3. Home Wi‑Fi & finding the portal

  • In Home network mode the buddy joins your router.
  • Browse to the IP shown on the OLED / serial log (e.g. http://192.168.x.x/). SoftAP setup uses http://192.168.4.1/.
  • If home Wi‑Fi fails, a recovery hotspot appears so you can fix settings.

4. Bluetooth & live typing

  • Open Typing & Bluetooth in the portal nav (or /typing.html). That page monitors keyboard mode only — it does not scan files or list SmartApplets, so your Neo stays in typing emulation. If Neo is stuck in ASM (manager) mode after a Documents action, tap Keyboard mode on that page.
  • Use Pair keyboard once so a phone/PC/tablet bonds the buddy as a Bluetooth keyboard (3-minute window for a new host). No PIN — tap Pair/Connect on the host. If a 6-digit code appears, confirm it (do not type a PIN). After flashing new firmware, remove Neo2 Buddy from the host Bluetooth list and use Forget bonded hosts on the buddy first — Windows especially caches the old HID profile.
  • Bonds are saved on the buddy. Use Forget bonded hosts in that dialog (or UART device ble clear) to erase them. Bluetooth stays off at boot until a host is already bonded (then it re-advertises for reconnect) or you start pairing from the portal.
  • While connected, keys you press on the Neo are typed on the phone/PC (live passthrough). The live viewer on the Typing page shows the same text.
  • ASM (manager) mode: Scan, backup, and file actions on the Documents page switch the Neo out of keyboard mode. While Bluetooth is connected, those actions may stop keystrokes reaching your paired device until keyboard mode returns (automatic after Backup now / Backup all).
  • Send text (from the Typing page or a backup on Documents) is optional for pasting longer portal text to the same host.

5. Cloud sync (optional)

  • Open Cloud sync, choose WebDAV, S3-compatible storage, or Hammer Ink, save, then Test connection.
  • Enable Auto cloud upload after backup in Settings if you want uploads after each successful backup.
  • Local copies stay on the buddy; cloud upload never deletes them.

6. SmartApplets & Applet Store

  • On the Documents page, use Applet Store to browse stock apps. In version 1.0.0, store installs are paused while those applets are retested. You can still install a .os3kapp file you already have.
  • You can download a copy of an installed applet or remove one. Refresh loads the list (briefly switches Neo to manager mode).
  • Flash Cards decks are edited in the portal deck library, then pushed to the Neo one set at a time.
  • Lean firmware profiles without Wi‑Fi/web have no portal Applet Store — use Full (or another Wi‑Fi build).

7. Password & factory reset

  • Change the portal password under Settings → Portal password.
  • Factory reset (Settings) requires re-entering the password. It clears settings and internal backups; SD card is kept.
  • Default password after a full flash / factory reset is neo2buddy until you complete setup again.

8. Serial CLI (advanced)

With UART enabled: login PASSWORD, then device factory-reset PASSWORD, help, or Neo/backup commands. See the firmware UART help. UART-slim firmware uses this console instead of the Wi‑Fi portal.
